# 音樂與音效響度校正

遊戲以預先量測的固定增益校正素材，不需每次開頁面重新下載、分析全部音訊。

- 現有 20 首 BGM（含絕技曲）與 19 個攻擊音效，以 ITU-R BS.1770 的 K 加權及響度閘門量測，播放響度皆對齊約 -18 LUFS。
- 素材本身使用相同校正基準；音樂預設 65%、音效預設 80%，可用頁面上方各自的滑桿調整。瀏覽器會保存這兩個音量，音樂開關仍預設關閉。
- 原始 MP3 保留。較小聲的 `attack_mat.mp3`、`attack_umb.mp3` 在 `audio-normalized/` 另製作同名副本，其餘素材以播放音量衰減校正。
- 使用固定增益，保留曲目內部的音量起伏；沒有加入動態壓縮或多音效限制器。
- `audio-levels.json` 記錄量測值、原檔雜湊、播放路徑及增益。遊戲內的 `AUDIO_LEVELS` 區塊內嵌相同播放資料，因此不依賴額外 JSON 載入。
- 絕技 BGM 的優先級、單次播放、結束後恢復戰鬥 BGM，維持既有規則。

新增或更換根目錄 `assets/*.mp3` 後，可從專案根目錄執行：

```powershell
python tools/calibrate-audio.py
```

校正工具需要 Python 的 `av`、`numpy` 與 `scipy`；遊戲本身不需要這些套件。工具會重建校正資料，並只對需要放大的音訊建立副本，原始檔不變。缺檔仍沿用原本的載入失敗與合成音效回退處理。
